# DomainStats

Статистика доменов для Velocity — можно посмотреть, с какого адреса приходят игроки, сколько раз они заходили и кто сейчас онлайн

Удобно, если у сервера несколько доменов или отдельные адреса для рекламы

## Установка

- Скачай `DomainStats-1.0.0.jar` из Releases
- Закинь JAR в папку `plugins` на прокси Velocity и перезапусти его
- Выдай себе право `domain.use` через LuckPerms на прокси

```text
/lpv user ТвойНик permission set domain.use true
```

Если у тебя уже есть `*`, команда тоже будет доступна
Явный запрет `domain.use false` перекрывает звёздочку
Из консоли команды работают без выдачи прав

## Команды

- `/domain` — список доменов, уникальные ники, все входы и онлайн
- `/domain play.example.org` — статистика конкретного домена
- `/domain players play.example.org` — кто заходил и сколько раз
- `/domain online play.example.org` — кто сейчас играет и на каком сервере
- `/domain list 2` — вторая страница доменов
- `/domain players play.example.org 2` — вторая страница игроков
- `/domain online play.example.org 2` — вторая страница онлайна
- `/domain reload` — перечитать настройки

На домены и кнопки страниц в чате можно нажимать
Для всех команд достаточно `domain.use`

## Как считаются входы

Один ник — один уникальный игрок для домена
Регистр не важен, поэтому `Nick` и `nick` считаются одним ником
Каждое повторное подключение увеличивает общее число входов
Переход между лобби и другими серверами внутри прокси новый вход не добавляет

Например, если один игрок зашёл пять раз, будет один уникальный ник и пять входов
Если он зайдёт с другого домена, появится и в статистике этого домена
В общем количестве уникальных ников он всё равно останется одним игроком

Учитываются только успешные подключения к серверу
Обновление списка серверов в клиенте и неудачные попытки входа в статистику не попадают
История начинается с установки плагина

## Настройки

Конфиг находится в `plugins/domainstats/config.properties`

```properties
domains=play.example.org,ads.example.org
import-forced-hosts=true
page-size=8
```

`domains` — адреса через запятую, которые нужно показывать даже без входов

`import-forced-hosts` — добавлять ли домены из раздела `forced-hosts` в настройках Velocity

`page-size` — сколько строк выводить на странице, от 1 до 30

После изменения конфига выполни `/domain reload`

Новые адреса появляются автоматически, когда с них заходит игрок
Узнать все DNS-записи, направленные на IP сервера, прокси не может — домены без входов нужно добавить в конфиг или `forced-hosts`
Эти настройки не меняют DNS и маршрутизацию игроков

Поддомены считаются отдельно, а регистр адреса и порт на статистику не влияют
Кириллические домены отображаются в punycode
Входы напрямую по IP тоже видны в списке
Если определить адрес не удалось, используется строка `unknown-host`

## Сохранение данных

Всё хранится в `plugins/domainstats/domains.db`
SQLite уже встроен в плагин, отдельная база не нужна
После перезапуска статистика остаётся, а онлайн заново определяется по подключениям

Для резервной копии останови прокси и скопируй папку `plugins/domainstats`
Удаление домена из конфига не стирает его историю
При аварийном завершении прокси последние события в очереди могут не успеть записаться

## Совместимость

Собран на API Velocity 3.3, проверен на Velocity 3.4 и 4.2 с LuckPerms 5.5.87 и клиентом Minecraft 1.16.4

Версия Minecraft в коде не зашита — для игроков от 1.16.4 до 26.2 нужна сборка Velocity с поддержкой соответствующих версий
Клиент 26.2 отдельно не проверялся
Java используй ту, которую требует твоя версия прокси

## Сборка из исходников

Нужны JDK 17 или новее и Maven 3

```sh
mvn clean package
```

Готовый JAR будет в `target/DomainStats-1.0.0.jar`
